Keep the runtime in Python Pulumi and use the official pinned Langfuse chart.
The cluster, runner, CNI, CSI and OIDC provider are existing platform inputs.
Keep services private and preserve native headless initialization independently
of the synthetic trace sample.

Acquire inert artifacts first, verify hashes, then complete malware coverage in
an approved sandbox before installing dependencies, rendering Helm, previewing
or executing workloads. Do not run the example on an unisolated workstation.
Use the compatible locked CPython 3.12 closure and exact image digests.

two-span observations, numeric score subject/value, and missing/wrong credential
denial. Health checks and synthetic parser tests do not establish that outcome.
